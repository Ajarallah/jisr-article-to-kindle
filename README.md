## لماذا جسر؟

أدوات «أرسل إلى كندل» تعالج المقال غالبًا بوصفه ملفًا إنجليزيًا عاديًا. جسر يعالج عملية القراءة كاملة: يلتقط الصفحة التي تراها، ويبني منها كتابًا عربيًا منضبطًا، ثم يرسله عبر جلسة Amazon المفتوحة في متصفحك.

## أبرز المزايا

### قراءة عربية سليمة

- اتجاه RTL على مستوى الكتاب والفصل والنص، مع عزل المقاطع الإنجليزية داخل العربية.
- تضمين خط أميري اختياريًا داخل EPUB لضمان تشكيل عربي ثابت على أجهزة كندل.
- أغلفة بمقاسات أجهزة كندل الحالية، مع عنوان ومؤلف قابلين للتحرير.
- معاينة القارئ قبل الإرسال، وفهرس مبني من عناوين المقال.

### ترجمة ودراسة

- ترجمة اختيارية عبر OpenRouter مع إعادة المحاولة، ومسار احتياطي، وإلغاء الطلب.
- وضع ثنائي اللغة يضع النص الأصلي إلى جوار ترجمته فقرةً فقرة.
- مسرد دراسي يحوّل المصطلحات الصعبة إلى حواشٍ منبثقة على الأجهزة الداعمة.
- حماية بنية المقال: لا تُترجم كتل الكود، وتبقى الروابط والعناصر في مواضعها.

### أكثر من مقال واحد

- تحويل ملفات Markdown وWord إلى EPUB.
- إرسال النص المظلّل فقط، أو اختيار منطقة من الصفحة يدويًا.
- جمع عدة مقالات في كتاب واحد متعدد الفصول.
- سجل إرسال محلي وخاص، مع إمكانية العودة إلى المصدر.

## البدء السريع

### المتطلبات

| المطلوب | السبب |
|---|---|
| Chrome أو Brave أو Edge أو Arc | متصفح Chromium يدعم Manifest V3 |
| حساب Amazon مرتبط بكندل | للإرسال المباشر إلى مكتبتك |
| مفتاح OpenRouter اختياري | للترجمة والمسرد فقط؛ بناء EPUB والإرسال لا يحتاجانه |

### التثبيت

```bash
git clone https://github.com/Ajarallah/jisr-article-to-kindle.git
```

1. افتح `chrome://extensions` أو `brave://extensions`.
2. فعّل **وضع المطوّر** (Developer mode).
3. اختر **تحميل إضافة غير محزّمة** (Load unpacked).
4. اختر مجلد `extension/` داخل المستودع.
5. افتح نطاق Amazon الذي تستخدمه وسجّل الدخول إلى الحساب المرتبط بكندل.

### إعداد الترجمة — اختياري

أدخل مفتاح OpenRouter من إعدادات جسر، أو أنشئ ملف الأسرار المحلي لنسخة التطوير:

```bash
cp extension/src/secrets.example.js extension/src/secrets.js
```

ثم ضع المفتاح في `extension/src/secrets.js`. الملف مستبعد من Git. لا تنشر مفتاحًا داخل حزمة عامة؛ الإضافات قابلة للفك واستخراج محتواها.

### الاستعمال

1. افتح مقالًا واضغط أيقونة **جسر**.
2. راجع العنوان والمؤلف والغلاف.
3. اختر الصور أو الترجمة أو الوضع الثنائي أو المسرد عند الحاجة.
4. اضغط **معاينة**، ثم **إرسال إلى كندل** أو **تنزيل EPUB**.

يظهر الكتاب عادة في مكتبة كندل خلال دقائق قليلة.

## كيف يعمل؟

```text
الصفحة المفتوحة
      ↓ استخراج محلي
محتوى نظيف + بيانات المقال
      ↓ ترجمة اختيارية
EPUB3 + غلاف + فهرس
      ↓ جلسة Amazon في المتصفح
مكتبة كندل
```

- يستخرج جسر المحتوى من DOM المعروض باستخدام Mozilla Readability مع مسار احتياطي للصفحات المعقدة.
- يبني EPUB كاملًا داخل الإضافة بواسطة JSZip؛ لا توجد خدمة مستضافة تابعة لجسر في مسار البناء أو الإرسال.
- عند تشغيل الترجمة أو المسرد فقط، يُرسل نص المقال إلى OpenRouter باستخدام المفتاح الذي يقدمه المستخدم.
- يرفع الإرسال المباشر الملف إلى Amazon عبر آلية Send to Kindle المعتمدة على جلسة المستخدم.

اقرأ [البنية التقنية](docs/architecture.md) و[تفاصيل آلية Send to Kindle](docs/03-official-s2k-mechanism.md).

## الخصوصية والصلاحيات

جسر لا يملك تحليلات أو تتبعًا أو حسابات مستخدمين أو خادم محتوى. تبقى الإعدادات والسجل والمفتاح داخل تخزين المتصفح، ولا يخرج نص المقال إلا إلى الخدمة التي اخترتها للعملية نفسها.

| الصلاحية | استخدامها |
|---|---|
| `activeTab` و`scripting` | قراءة المقال عند ضغط المستخدم على الإضافة فقط |
| `storage` | حفظ الإعدادات والسجل محليًا |
| نطاقات Amazon وAmazon S3 | التحقق من الجلسة ورفع EPUB إلى مكتبة كندل |
| `openrouter.ai` | الترجمة والمسرد عند تشغيلهما فقط |
| صلاحية موقع اختيارية | تضمين صور المقال من ذلك الموقع عند طلب المستخدم |

التفاصيل في [سياسة الخصوصية](store/PRIVACY.md).

## دليل المستودع

| المسار | دوره |
|---|---|
| `extension/` | المنتج الفعلي: إضافة Manifest V3 والواجهات وبناء EPUB والإرسال |
| `extension/src/` | الاستخراج والترجمة والأغلفة والمعاينة والتوصيل والإعدادات |
| `extension/lib/` | المكتبات والخطوط المضمّنة للعمل دون خطوة بناء |
| `server/` | بيئة Node للاختبارات وESLint وإنشاء الأيقونات؛ ليس خادم تشغيل |
| `docs/` | الأبحاث والقرارات والبنية وتفاصيل بروتوكول الإرسال |
| `store/` | نص متجر Chrome وسياسة الخصوصية وتبريرات الصلاحيات |
| `scripts/` | بناء حزمة الإضافة القابلة للرفع إلى المتجر |
| `media/` | صور المشروع المستخدمة في التوثيق |

<a id="development"></a>

## التطوير

يتطلب تشغيل الاختبارات Node.js 18 فأحدث:

```bash
cd server
npm ci
npm run lint
npm test
```

لبناء ملف ZIP نظيف للإضافة:

```bash
./scripts/package-extension.sh
```

لا يحتاج الكود داخل `extension/` إلى bundler أو خادم تطوير؛ حمّل المجلد مباشرة في المتصفح، ثم أعد تحميل الإضافة بعد التعديل.

## حالة المشروع وحدوده

| البند | الحالة |
|---|---|
| الإصدار الحالي | `0.3.0` |
| مرحلة المشروع | ما قبل الإصدار |
| الاختبارات | 54 اختبارًا آليًا + ESLint + GitHub Actions |
| الإرسال المباشر | متحقق منه عبر مسار Amazon Send to Kindle |
| النشر في Chrome Web Store | لم يُنشر بعد؛ التثبيت يدوي حاليًا |

قبل الإصدار العام، يحتاج جسر إلى اختبارات متكررة على أجهزة كندل فعلية للعربية والكتب الثنائية والحواشي والصور، وإلى نقل أي مفتاح ترجمة مضمّن خلف وسيط يتحكم به الناشر. كما أن نقاط Amazon خاصة وغير موثقة، ولذلك سيبقى تنزيل EPUB مسارًا احتياطيًا دائمًا.
